# Farmacia

Preparación local del proyecto académico de Vicente Durán e Ignacio Aqueveque.

| Carpeta | Uso |
|---|---|
| [backend](backend/) | Base Django reutilizada. Contiene modelos, migraciones, reglas, pruebas y la interfaz anterior para referencia y regresión. La configuración normal de Django apunta a PostgreSQL. |
| [frontend](frontend/) | Espacio para la aplicación web independiente que consumirá la API. |
| [docs](docs/) | Alcance, Kanban, decisiones y material previo de referencia. |

Empezar por la [matriz de alcance](docs/matriz-alcance.md), el [tablero Kanban](docs/kanban.md) y las [decisiones pendientes](docs/decisiones.md). Para levantar esta entrega, seguir la [guía de PostgreSQL local](docs/postgresql-local.md). El README del backend describe el prototipo anterior.
