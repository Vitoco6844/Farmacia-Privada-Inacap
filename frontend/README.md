# Frontend independiente

La nueva interfaz vivirá en esta carpeta y usará una API para iniciar sesión, consultar datos y ejecutar operaciones. Las reglas de negocio, permisos y transacciones se ejecutarán en el backend. Las plantillas de la versión anterior sirven como referencia para los recorridos.

Al implementar el primer flujo se elegirá la herramienta del frontend y se definirá un contrato de API con casos de éxito, error y permisos. La primera prueba integrada debe ejecutar el flujo desde esta interfaz hasta Django y PostgreSQL local.
